# Shared pieces

Small parts reused by many sections. Nothing here is a strip of the page on its
own — edit one of these and it changes everywhere it's used at once.

| File               | What it does                                                |
| ------------------ | ----------------------------------------------------------- |
| `Eyebrow.tsx`      | The small uppercase label above a section heading            |
| `Reveal.tsx`       | Fades content in as you scroll to it                         |
| `Words.tsx`        | Splits a headline into words so they can animate one by one  |
| `Magnetic.tsx`     | Makes a button drift toward the mouse cursor                 |
| `CardRail.tsx`     | The curved, draggable row of cards (Services and Why Us)      |
| `Aurora.tsx`       | The animated colour glow behind the opening screen           |
| `SmoothScroll.tsx` | Turns the whole page's scrolling smooth (loaded once)        |
| `ContactDialog.tsx`| The pop-up that takes your details at the end of the estimator |
